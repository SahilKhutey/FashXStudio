# Responsive Layout Rules
Rules governing layout responsiveness:
- `mobileSmall` (320px): Strictly 1 column. Horizontal scrolling is prohibited.
- `mobile` (375px): Maximum 2 columns; compact or comfortable density.
- `tablet` (768px): Up to 4 columns.
- `desktop` (1024px): Up to 6 columns.
- `desktopLarge` (1440px): Up to 6 columns.
