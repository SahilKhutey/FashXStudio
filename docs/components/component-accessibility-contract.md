# Component Accessibility Contract
Accessibility invariants:
- Contrast ratio >= 4.5:1 for standard body text; >= 3.0:1 for large text.
- Interactive controls must have a visible focus ring (--mm-focus-ring-color).
- Minimum touch target dimension of 44x44px.
- Full keyboard navigation (Tab, Shift-Tab, Enter, Space, Escape for modals).
