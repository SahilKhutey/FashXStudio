# ARC-08: 07 — Layout Architecture

## 1. Initial Layout Catalogue
ModularMenu provides 4 foundational layouts:
1. **Compact List (`layout-list`)**: Vertical text-forward listing designed for rapid scanning.
2. **Responsive Grid (`layout-grid`)**: Balanced multi-column grid of uniform dish cards.
3. **Image-Forward Cards (`layout-image-cards`)**: Photography-first layout showcasing high-resolution culinary imagery.
4. **Editorial Sections (`layout-editorial`)**: Magazine-style narrative sections with featured heroes.

## 2. Structural Settings
- `columns`: Configurable between 1 and 6 columns.
- `density`: `compact`, `comfortable`, or `spacious`.
- `image_position`: `top`, `left`, `right`, or `none`.
- `category_navigation_style`: `pills`, `tabs`, `sticky-bar`, or `sidebar`.
