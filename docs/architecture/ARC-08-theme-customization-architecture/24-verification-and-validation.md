# ARC-08: 24 — Verification and Validation Scenarios

## 1. Scenarios (VAL-01 to VAL-08)
- **VAL-01**: Restaurant onboarding and first theme selection.
- **VAL-02**: Complete customization workflow (colors, typography, spacing).
- **VAL-03**: Visual editor workflow (component addition, reordering, visibility).
- **VAL-04**: Cross-tenant isolation verification.
- **VAL-05**: Theme upgrade compatibility and version pinning.
- **VAL-06**: Malicious input and schema injection rejection.
- **VAL-07**: Concurrent editor sessions and ETag conflict handling.
- **VAL-08**: SaaS and self-hosted configuration portability.
