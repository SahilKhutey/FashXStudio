# RC-00 — Repository & Runtime Audit

## Objective
Establish an evidence-based technical baseline for FashXStudio before beginning the next development cycle.

## Scope
- Repository and Git history.
- Backend architecture.
- Mobile application architecture.
- API contracts.
- Database schema and migrations.
- Catalog acquisition and product data.
- Discovery and recommendation.
- Virtual try-on and AI provider.
- Authentication and privacy.
- Runtime configuration.
- Automated testing and CI.
- Physical-device execution.

## Non-goals
- No feature development.
- No database migration.
- No data deletion.
- No production configuration changes.
- No commerce scope expansion.
- No direct changes to main.

## Audit Principles
1. Evidence before conclusions.
2. Separate confirmed defects from risks.
3. Never expose secrets in reports.
4. Preserve existing application behavior.
5. Verify the actual runtime independently from source code.
6. Record exact file paths, commands, and test results.

## Exit Condition
A complete technical baseline, root-cause register, dependency map, and approved implementation backlog for RC-01 through RC-07.
