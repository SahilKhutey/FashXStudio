# RC07 — Behavioral Personalization & Taste Vector Engine

## 1. Objective
Construct a personalized user taste vector from verified behavioral interactions, applying action-specific weights and exponential time decay while preventing cross-model vector corruption.

## 2. Mathematical Formulation
Given a set of user interactions $S = \{(e_i, w_i, t_i)\}$ compatible with target model $M$:

$$\text{Decay}(t_i, t_{\text{now}}) = 0.5^{\frac{\Delta t_{\text{days}}}{14.0}}$$

$$\mathbf{u}_{\text{accum}} = \sum_{i \in S} w_i \cdot \text{Decay}(t_i, t_{\text{now}}) \cdot \mathbf{e}_i$$

$$\mathbf{u}_{\text{taste}} = \frac{\mathbf{u}_{\text{accum}}}{\|\mathbf{u}_{\text{accum}}\|_2}$$

## 3. Signal Weights Table
| Action | Weight | Source Table | Interpretation |
|---|---|---|---|
| `try_on` | +1.5 | `tryon_jobs` | Strongest visual engagement |
| `save` | +1.2 | `wardrobe_items` | Explicit purchase interest |
| `like` | +1.0 | `feed_signals` | Positive discovery affinity |
| `hide` | -1.0 | `feed_signals` | Negative visual preference |
| `not_interested` | -1.0 | `feed_signals` | Negative style preference |

## 4. Cross-Model Isolation
If a signal was generated by a different model ID or version than the current recommendation model, it is strictly filtered out. If no compatible positive signals exist, `build_taste_vector` returns `None`, allowing cold-start fallback to pure deterministic preference compatibility.

## 5. Verification
Unit test `tests/unit/test_rc07_taste_vector.py` verifies:
- Cold start returns `None`.
- Incompatible model signals are excluded.
- 14-day and 28-day exponential decay calibration.
- Negative signal vector opposition and rejection when only negative signals exist.
