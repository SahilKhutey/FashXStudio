## 2. Test Execution Commands
```bash
# RC10 Unit Suite
pytest tests/unit/test_rc10_timing.py \
       tests/unit/test_rc10_catalog_quality.py \
       tests/unit/test_rc10_recommendation_evaluation.py \
       tests/unit/test_rc10_metrics.py -q

# RC10 Release & Beta Gates
pytest tests/release/test_rc10_beta_gates.py -q

# RC10 Integration & Security Suites
pytest tests/integration/test_rc10_shopping_regression.py \
       tests/integration/test_rc10_vto_reliability.py \
       tests/security/test_rc10_privacy_regression.py -q

# Mobile Type & Unit Checks
cd mobile && npx tsc --noEmit && npx eslint . --max-warnings 0 && npx jest --ci
```

## 3. Strict Verification Guidelines
Under `AGENTS.md` Rule 2 and Rule 13:
- Tests must be run against genuine fixtures or running services.
- Never write results or verdicts unless generated by actual command executions.
