# Limitations & Boundary Conditions

> **Known technical constraints and intentional boundaries.**

## 1. Known Product Limitations
1. **No Automated Body Measurement Extraction from Single Selfie**:
   Single consumer selfies taken on mobile phones cannot accurately extract millimeter-precise body measurements without calibrated reference markers or depth sensors. Therefore, shopper measurements must be provided explicitly by the user or calibrated measuring tools.
2. **Indian Ethnic Multi-Piece Sizing**:
   Garments with adjustable drawstrings (e.g., lehenga skirts) or unstitched drapes (sarees) do not have standard chest/waist ease formulas. Sizing models for these categories remain marked as `UNSUPPORTED_CATEGORY`.
3. **Merchant Size Chart Non-Standardization**:
   Different apparel brands define size labels (e.g., "M") with varying dimensional tolerances. Sizing advice is strictly comparative against the specific merchant's verified chart, not an absolute universal sizing standard.
