# Merchant Widget Policy: B2B Integration Constraints

> **Customization boundaries for embedded merchant storefront widgets.**

## 1. Permitted Customizations
Merchants integrating the FashXStudio storefront widget may customize:
- Color palette and themes (primary, background, text colors).
- Container borderRadius and typography scale.
- Button styling and layout orientation.
- Placement within the merchant PDP (Product Detail Page).

## 2. Prohibited Customizations (Non-Negotiables)
Merchants are strictly prohibited from:
- Removing, hiding, or obscuring the Visual Simulation Disclaimer (`show_disclaimer=True` is server-locked).
- Relabeling the result as "Verified Fit", "Guaranteed Fit", or "Exact Size".
- Providing arbitrary merchant-created fit guarantees.
- Suppressing the size chart provenance source label.
