# Phase 07.4.15 — Security and Privacy Architecture Review

## 1. Overview
The Virtual Try-On pipeline processes biometric-adjacent customer photographs and proprietary merchant catalog imagery. Under India's Digital Personal Data Protection (DPDP) Act and global privacy standards, the architecture must guarantee data minimization, strict isolation, zero-PII telemetry, and defense against network injection attacks.

---

## 2. Threat Modeling & Safeguards

| Threat Vector | Severity | Mitigation Architecture | Verification |
| :--- | :--- | :--- | :--- |
| **Server-Side Request Forgery (SSRF)** | Critical | `is_safe_provider_output_url` rejects non-HTTPS, unapproved domains, and loopback/private IP spaces (`127.0.0.1`, `169.254.169.254`, `10.0.0.0/8`). HTTP redirects are disabled. | Verified in `test_output_validation.py` (3 SSRF tests) |
| **Image Decompression Bomb (DoS)** | High | Hard byte cap ($15.0\text{ MB}$) before Pillow loading; maximum pixel cap ($20\text{ MP}$); full Pillow `Image.open` and `verify()` pass. | Verified in `test_output_validation.py` |
| **Cross-Tenant Asset Enumeration** | High | Requesting another user's photo returns `404 Not Found` (anti-enumeration); querying result URL of another user's job returns `404 Not Found`. | Verified in `test_accept_job_use_case.py` |
| **DPDP Consent Revocation Race** | High | Time-of-use recheck in worker right before provider dispatch; immediate abort to `PERMISSION_BLOCKED` if consent is revoked. | Verified in `test_time_of_use_guard.py` |
| **PII Leakage in Telemetry & Logs** | Medium | Outbox messages contain only UUIDs; `TryOnUsage` logs contain no user IDs or image URLs; error details scrub secret tokens and auth headers. | Verified in `test_fashn_live_provider.py` |
| **Unauthorized Result Access** | High | S3 buckets have block public access enabled; result URLs are presigned S3 GET requests with 300-second expiration. | Architecture enforced in `TryOnRouter` and `S3Storage` |

---

## 3. DPDP Compliance Attestation

1. **Explicit Notice & Purpose Limitation**: Body photos are processed solely for the requested virtual try-on action.
2. **Right to Withdraw**: If a shopper withdraws `THIRD_PARTY_VTO_PROCESSING` consent, all pending jobs are blocked, and previously cached artifacts are marked ineligible for reuse.
3. **Data Retention & Pruning**: Try-on artifacts are tagged with expiration timestamps (`expires_at`), and S3 lifecycle policies prune raw results after 30 days.
