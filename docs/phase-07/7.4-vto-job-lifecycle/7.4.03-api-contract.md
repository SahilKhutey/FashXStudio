# Phase 07.4.03 — API Contract Specification

## 1. Overview
The Virtual Try-On API defines the boundary between client applications (mobile iOS/Android, merchant web) and the asynchronous inference pipeline. The API operates strictly asynchronously: requests return **HTTP 202 Accepted** in $< 150 \text{ ms}$, ensuring no HTTP connections remain open during inference.

All endpoints require JWT Bearer authentication. Identity is derived strictly from the verified JWT principal (`principal.user_id`). Client-supplied `user_id` fields are forbidden (`extra = "forbid"`).

---

## 2. Endpoints Summary

| Method | Path | Description | Success Code | Error Codes |
| :--- | :--- | :--- | :--- | :--- |
| `POST` | `/api/v1/tryon/jobs` | Submit a new try-on job or retrieve idempotent existing job | `202 Accepted` | 400, 401, 403, 404, 409, 422, 429, 503 |
| `GET` | `/api/v1/tryon/jobs/{job_id}` | Poll current job status and progress stage | `200 OK` | 401, 404 |
| `GET` | `/api/v1/tryon/jobs/{job_id}/result`| Retrieve signed, short-lived URL for generated result | `200 OK` | 401, 404, 409 |
| `POST` | `/api/v1/tryon/jobs/{job_id}/cancel`| Cancel an unsubmitted queued job | `200 OK` | 401, 404, 409 |

## 3. Detailed Endpoint Contracts

### 3.1 Submit Try-On Job
- **URL**: `/api/v1/tryon/jobs`
- **Method**: `POST`
- **Headers**:
  - `Authorization: Bearer <jwt_token>` (Mandatory)
  - `Idempotency-Key: <uuid_or_opaque_string>` (Optional but recommended)
  - `Content-Type: application/json`

#### Request Schema
```json
{
  "shopper_image_asset_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "product_id": "1fa85f64-5717-4562-b3fc-2c963f66afa1",
  "garment_image_asset_id": "2fa85f64-5717-4562-b3fc-2c963f66afa2",
  "category": "tops",
  "idempotency_key": "optional-client-supplied-key"
}
```

#### Response: HTTP 202 Accepted
```json
{
  "job_id": "9fa85f64-5717-4562-b3fc-2c963f66afa9",
  "status": "QUEUED",
  "progress_stage": "QUEUED",
  "status_url": "/api/v1/tryon/jobs/9fa85f64-5717-4562-b3fc-2c963f66afa9",
  "estimated_wait_seconds": 12,
  "created_at": "2026-11-24T09:40:00Z"
}
```

#### Error Mappings
| Status Code | Code / Condition | Meaning |
| :--- | :--- | :--- |
| `401 Unauthorized` | `unauthorized` | Missing, malformed, or expired JWT. |
| `403 Forbidden` | `consent_required` | DPDP `THIRD_PARTY_VTO_PROCESSING` consent missing or revoked. |
| `404 Not Found` | `photo_not_found` | Shopper image does not exist or belongs to another user (anti-enumeration). |
| `404 Not Found` | `garment_not_found`| Product or garment image asset does not exist. |
| `409 Conflict` | `idempotency_conflict` | Same `Idempotency-Key` presented with differing payload parameters. |
| `422 Unprocessable`| `unsupported_category` | Garment category is unsupported (e.g. footwear, accessories). |
| `422 Unprocessable`| `validation_failed` | Input image failed initial validation rules (corrupt, low resolution). |
| `429 Too Many Req` | `rate_limit_exceeded` | Concurrency limit reached for shopper account. |

### 3.2 Poll Job Status
- **URL**: `/api/v1/tryon/jobs/{job_id}`
- **Method**: `GET`
- **Headers**:
  - `Authorization: Bearer <jwt_token>`

#### Response: HTTP 200 OK
```json
{
  "job_id": "9fa85f64-5717-4562-b3fc-2c963f66afa9",
  "status": "PROCESSING",

  "updated_at": "2026-11-24T09:40:04Z",

```

### 3.3 Get Result Image URL
- **URL**: `/api/v1/tryon/jobs/{job_id}/result`
- **Method**: `GET`
- **Headers**:
  - `Authorization: Bearer <jwt_token>`

#### Security & Access Rules
1. Returns `404 Not Found` if `job_id` does not exist or if `job.user_id != principal.user_id` (strict anti-enumeration).
2. Returns `409 Conflict` if the job is not yet in `COMPLETED` state.
3. Does not serve binary payload through the application server; returns a presigned, expiring URL directly to the private S3 storage.

#### Response: HTTP 200 OK
```json
{
  "job_id": "9fa85f64-5717-4562-b3fc-2c963f66afa9",
  "result_url": "https://fashx-results-staging.s3.ap-south-1.amazonaws.com/tryon-results/9fa85f64-5717-4562-b3fc-2c963f66afa9.jpg?X-Amz-Security-Token=...",
  "expires_in_seconds": 300,
  "content_type": "image/jpeg"
}
```
