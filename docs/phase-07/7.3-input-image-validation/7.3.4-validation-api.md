# Phase 07.3.4 — VTO Input Validation API Specification

## 1. Overview
This document specifies the REST API endpoints and data transfer contracts for virtual try-on input validation. Validation is offered both as an upfront pre-check for the mobile application to guide shoppers before submission, and as an enforced server-side gate during try-on job creation.

---

## 2. API Endpoints

### 2.1 Pre-Validation Endpoint
Allows the mobile client to pre-screen a selected shopper photo and garment prior to initiating a job.

- **Route**: `POST /api/v1/tryon/validate-inputs`
- **Auth**: Bearer JWT (`Shopper`)
- **Rate Limit**: 30 requests/minute per authenticated user

### 2.2 Try-On Job Creation Endpoint
Integrates the mandatory validation gate into the job creation flow.

- **Route**: `POST /api/v1/tryon/jobs`
- **Auth**: Bearer JWT (`Shopper`)
- **Enforcement**:
  - Automatically invokes `CombinedValidator` before job is persisted.
  - If validation returns `REJECTED`, `EXPIRED`, `NEEDS_REVIEW`, or `ERROR`, the job is not queued and an HTTP 422 Unprocessable Entity is returned with structured issue codes.
  - If validation returns `PASSED` or `PASSED_WITH_WARNINGS`, the validation records are linked to the job, and the job transitions to `QUEUED`.

#### Error Response (422 Unprocessable Entity)
```json
{
  "error": "TRYON_VALIDATION_FAILED",
  "message": "Virtual try-on inputs failed mandatory validation checks.",
  "status": "REJECTED",
  "issues": [
    {
      "code": "BODY_REGION_NOT_VISIBLE",
      "message": "Required body region(s) missing for category 'tops': shoulders, torso.",
      "remediation": "Please select or take a photo clearly showing your upper body including shoulders and chest.",
      "severity": "ERROR",
      "blocking": true,
      "details": {
        "category": "tops",
        "missing_regions": ["shoulders", "torso"]
      }
    }
  ]
}
```

#### Authorization Error Response (403 Forbidden)
Returned when consent is missing, revoked, or merchant licensing is absent:
```json
{
  "error": "VTO_CONSENT_REQUIRED",
  "message": "Shopper has not granted consent for virtual try-on processing.",
  "remediation": "Please accept the Virtual Try-On privacy terms to enable fitting simulation."
}
```

#### Asset Not Found / Anti-Enumeration Error (404 Not Found)
Returned when the photo asset ID does not belong to the user or does not exist:
```json
{
  "error": "IMAGE_NOT_OWNED_OR_NOT_FOUND",
  "message": "Shopper photograph asset not found or not owned by user."
}
```

## 3. Status Codes Mapping

| HTTP Status | Trigger Condition |
| :--- | :--- |
| `200 OK` | Pre-validation completed (carries `overall_status` in body). |
| `201 Created` | Job creation succeeded, inputs passed validation, job queued. |
| `400 Bad Request` | Malformed JSON, invalid UUID formats, unknown category parameter. |
| `403 Forbidden` | Missing shopper consent (`VTO_CONSENT_REQUIRED`) or missing merchant permission. |
| `404 Not Found` | Asset ID not found or cross-tenant ownership violation (anti-enumeration). |
| `409 Conflict` | Garment status is delisted, discontinued, or in active takedown. |
| `422 Unprocessable Entity` | Technical or visual validation check failed (low res, bad pose, occluded body). |
| `503 Service Unavailable` | Validation infrastructure or object store unavailable. |
