# Phase 07.3.2 — Garment Image Validation Specification

## 1. Overview
The garment image validation subsystem ensures that merchant product imagery submitted for Virtual Try-On has verified licensing rights, exact product association, container integrity, and visual apparel suitability.

---

## 2. Validation Stages

### Stage 1: Product and Merchant Status
- Product Record: Must be present in the catalog (`CanonicalGarment` / `MerchantProduct`).
- Status Check: Products in `DELISTED`, `TAKEDOWN`, `SUSPENDED`, or `DISCONTINUED` status return `ValidationStatus.REJECTED` with error `PRODUCT_NOT_ACTIVE`.
- Source Verification: The underlying `CatalogSource` and `Merchant` must be in active status.

### Stage 2: Product-to-Image Association
- Verification: The submitted `image_asset_id` must be authoritatively registered to the target `product_id`.
- Anti-Spoofing: Submitting an image belonging to a different product triggers `IMAGE_PRODUCT_MISMATCH`.

### Stage 3: Merchant Permission Scope
- In accordance with Phase 05 authorization architecture:
  - `IMAGE_AI_PROCESS`: Permission to send the garment image to AI processing pipelines.
  - `VTO_PROCESS`: Specific permission to utilize the garment image for virtual try-on fitting.
  - `IMAGE_STORE` and `IMAGE_DISPLAY`: Base storage and display permissions.
- Takedown Check: Rejects if an active takedown request exists for the asset or source.
- Missing permissions trigger `GARMENT_PROCESSING_NOT_AUTHORIZED`.

### Stage 4: Technical Quality & Dimensions
- Enforces the same minimum 512×512 px and maximum 4096×4096 px / 10 MB limits as shopper photographs.
- Rejects corrupt or truncated images with `IMAGE_CORRUPTED`.

### Stage 5: Garment Visual Suitability
- Visibility: Garment boundaries must be distinguishable (`GARMENT_NOT_VISIBLE` if undetected).
- Cropping: Rejects severe close-up collar/cuff thumbnails or fabric swatches.
- Background Suitability: Checks contrast and clutter. High clutter yields `PASSED_WITH_WARNINGS` with `GARMENT_BACKGROUND_UNSUITABLE`.
- Category Support: Unsupported categories (footwear, jewellery) trigger `UNSUPPORTED_GARMENT_CATEGORY`.
