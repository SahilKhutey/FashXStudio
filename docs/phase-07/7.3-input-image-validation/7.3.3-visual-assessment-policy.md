## 2. Visual Assessment Rules

### A. Shopper Evaluation
1. **Person Count**:
   - `person_detected == False`: REJECT (`PERSON_NOT_DETECTED`).
   - `person_count > 1`: REJECT (`MULTIPLE_PEOPLE_DETECTED`).
2. **Pose Suitability**:
   - `UPRIGHT_FRONT` or `ANGLED`: PASS.
   - `LYING_DOWN`: REJECT (`POSE_UNSUPPORTED`).
3. **Region Coverage**:
   - Must cover 100% of the category's `required_regions`. Any missing region results in `BODY_REGION_NOT_VISIBLE`.
4. **Occlusion Handling**:
   - `SEVERE` (hands/bags fully blocking target garment zone): REJECT (`BODY_REGION_OCCLUDED`).
   - `MINOR` (small wrist/accessory overlap): WARNING (`PASSED_WITH_WARNINGS`).

### B. Garment Evaluation
1. **Garment Visibility**:
   - Must detect the main garment silhouette.
   - Fabric swatches or tiny collar thumbnails: REJECT (`GARMENT_NOT_VISIBLE`).
2. **Background Suitability**:
   - Extreme background clutter or camouflage: WARNING (`GARMENT_BACKGROUND_UNSUITABLE`).
