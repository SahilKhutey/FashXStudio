# Phase 07.3.1 — Shopper Image Validation Specification

## 1. Overview
The shopper image validation subsystem enforces authorization, ownership, container integrity, and visual body suitability before any shopper photograph can be queued or submitted to an external Virtual Try-On provider.

---

## 2. Validation Pipeline Stages

### Stage 1: Authoritative Consent
- Purpose: Verify that the shopper has explicitly authorized third-party AI image processing.
- Purpose Tag: `THIRD_PARTY_VTO_PROCESSING` (with fallback to `body_photo`).
- Enforcement: Queried directly from `ConsentRecord` / `ConsentEvent`. Missing or withdrawn consent immediately returns `ValidationStatus.REJECTED` with error `VTO_CONSENT_REQUIRED`.

### Stage 2: Ownership and Asset Isolation
- Anti-Enumeration Principle: Access to a photo asset requires `user_id == authenticated_user_id`.
- Rejection of Cross-User Access: If a user specifies an asset ID owned by another user or non-existent, the endpoint returns `IMAGE_NOT_OWNED_OR_NOT_FOUND` without disclosing the asset's existence.
- Asset Status Check: Assets must be in `accepted` or `AVAILABLE` status.

### Stage 3: Technical Inspection
- Managed by `ImageInspector` (`backend/fashx/tryon/validation/image_inspector.py`).
- Supported Formats: `JPEG`, `PNG`, `WEBP`.
- Dimensions: Minimum 512×512 px; Maximum 4096×4096 px. Maximum pixels: 20,000,000.
- Maximum Size: 10 MB.
- Normalization: EXIF orientation tags are transposed via `ImageOps.exif_transpose`, color space converted to RGB, and re-encoded to a clean JPEG raster.

### Stage 4: Category-Specific Body Visibility
- Evaluated against `CategoryPolicy` (`backend/fashx/tryon/validation/category_policy.py`).
- Tops (T-shirts, shirts, kurtas): Requires `shoulders` and `torso`.
- Bottoms (trousers, pants): Requires `waist` and `legs`.
- One-pieces (dresses): Requires `shoulders`, `torso`, and `legs`.
- Missing required regions triggers `BODY_REGION_NOT_VISIBLE`.

### Stage 5: Pose, Occlusion, and Confidence
- Supported Pose: Upright, forward-facing or slightly angled. Poses labeled `LYING_DOWN` trigger `POSE_UNSUPPORTED`.
- Occlusion: Severe obstruction over the target garment area triggers `BODY_REGION_OCCLUDED`. Minor occlusion yields `PASSED_WITH_WARNINGS`.
- Confidence Threshold: Heuristic/model confidence below `0.80` returns `NEEDS_REVIEW`.
