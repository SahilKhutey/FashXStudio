# Phase 07.3.7 — VTO Input Validation Test Plan

## 1. Scope & Objective
This test plan defines the automated and manual test scenarios required to verify the Virtual Try-On Input Image Validation subsystem across technical integrity, authorization, category policy, visual assessment, combined orchestration, and time-of-use security guards.

---

| Test Suite | File Location | Scenarios Covered |

| **Technical Inspector** | `tests/unit/tryon/validation/test_image_inspector.py` | IMG-001 – IMG-008 |

## 3. Test Cases Matrix

### 3.1 Technical Image Inspection (`IMG`)

| ID | Title | Description | Expected Outcome |
| :--- | :--- | :--- | :--- |
| `IMG-001` | Valid JPEG Normalization | Submit clean 600×800 JPEG within size limits. | Success; normalized JPEG generated; SHA-256 computed. |
| `IMG-002` | Valid PNG to JPEG Conversion | Submit clean 600×800 PNG. | Success; converted to RGB JPEG raster; hashes match specs. |
| `IMG-003` | Valid WebP Conversion | Submit clean 600×800 WebP raster. | Success; converted to RGB JPEG raster. |
| `IMG-004` | Unsupported Format Rejection | Submit GIF or TIFF format bytes. | `IMAGE_FORMAT_UNSUPPORTED` error; blocked. |
| `IMG-005` | Corrupted Image Rejection | Submit random unparseable bytes. | `IMAGE_CORRUPTED` error; blocked. |
| `IMG-006` | Low Resolution Rejection | Submit 400×400 px image (below 512×512 minimum). | `IMAGE_RESOLUTION_TOO_LOW` error; blocked. |
| `IMG-007` | Excessive Dimensions Rejection | Submit 5000×5000 px image (above 4096×4096 limit). | `IMAGE_DIMENSIONS_TOO_LARGE` error; blocked. |
| `IMG-008` | EXIF Orientation Transposition | Submit JPEG with EXIF orientation flag 6 (90° rot). | Transposed to upright orientation before hashing. |

### 3.2 Shopper Validation (`SHP`)

| ID | Title | Description | Expected Outcome |
| :--- | :--- | :--- | :--- |
| `SHP-001` | Missing Consent Rejection | Shopper without `THIRD_PARTY_VTO_PROCESSING` consent. | `VTO_CONSENT_REQUIRED` error; blocked. |
| `SHP-002` | Missing Asset Rejection | Asset ID does not exist or belongs to another user. | `IMAGE_NOT_OWNED_OR_NOT_FOUND` error; blocked (anti-enumeration). |
| `SHP-003` | Technical Failure Forwarding | Corrupt or invalid resolution shopper image. | Propagates technical error code; blocked. |
| `SHP-004` | No Person Detected | Visual assessment finds no human silhouette. | `PERSON_NOT_DETECTED` error; blocked. |
| `SHP-005` | Multiple People Detected | Visual assessment finds 2 or more people. | `MULTIPLE_PEOPLE_DETECTED` error; blocked. |
| `SHP-006` | Missing Body Regions for Category | Category `tops` missing shoulders/torso. | `BODY_REGION_NOT_VISIBLE` error; blocked. |
| `SHP-007` | Unsupported Pose (Lying Down) | Pose classified as `LYING_DOWN`. | `POSE_UNSUPPORTED` error; blocked. |
| `SHP-008` | Severe Occlusion | Hand or large handbag covering 60%+ of torso. | `BODY_REGION_OCCLUDED` error; blocked. |
| `SHP-009` | Minor Occlusion (Warning) | Small wristwatch or hand at border. | `PASSED_WITH_WARNINGS` with non-blocking warning. |
| `SHP-010` | Low Model Confidence | Visual assessment confidence 0.65 (< 0.80). | `NEEDS_REVIEW` with `VISUAL_ASSESSMENT_UNCERTAIN`. |

### 3.3 Garment Validation (`GAR`)

| ID | Title | Description | Expected Outcome |
| :--- | :--- | :--- | :--- |
| `GAR-001` | Product Inactive Rejection | Product status is `DELISTED` or `DISCONTINUED`. | `PRODUCT_NOT_ACTIVE` error; blocked. |
| `GAR-002` | Image Product Mismatch | Garment image asset ID not linked to product ID. | `IMAGE_PRODUCT_MISMATCH` error; blocked. |
| `GAR-003` | Missing Merchant Permission | Merchant has not granted `IMAGE_AI_PROCESS` / `VTO_PROCESS`. | `GARMENT_PROCESSING_NOT_AUTHORIZED` error; blocked. |
| `GAR-004` | Unsupported Category Rejection | Garment category is `footwear` or `jewellery`. | `UNSUPPORTED_GARMENT_CATEGORY` error; blocked. |
| `GAR-005` | Pending Category Rejection | Garment category is `saree` (ethnic drape). | `UNSUPPORTED_GARMENT_CATEGORY` error; blocked. |
| `GAR-006` | Garment Not Visible | Image is a swatch or tiny collar thumbnail. | `GARMENT_NOT_VISIBLE` error; blocked. |
| `GAR-007` | Background Unsuitable (Warning) | Complex cluttered background. | `PASSED_WITH_WARNINGS` with non-blocking warning. |

### 3.4 Combined Orchestration (`COM`)

| ID | Title | Description | Expected Outcome |
| :--- | :--- | :--- | :--- |
| `COM-001` | Both Valid Passing | Clean shopper and garment images for valid category. | `PASSED`; overall result approved for submission. |
| `COM-002` | Shopper Fails, Garment Valid | Low-res shopper photo with valid garment. | `REJECTED`; overall result blocked; details shopper issue. |
| `COM-003` | Garment Fails, Shopper Valid | Missing merchant permission with valid shopper photo. | `REJECTED`; overall result blocked; details garment issue. |
| `COM-004` | Warning Aggregation | Valid shopper with cluttered garment background. | `PASSED_WITH_WARNINGS`; overall result allowed. |

### 3.5 Time-of-Use Guards (`TOU`)

| ID | Title | Description | Expected Outcome |
| :--- | :--- | :--- | :--- |
| `TOU-001` | Shopper Consent Revocation at TOU | Consent revoked between job queuing and worker pick up. | Job status set to `FAILED`; provider submission prevented. |
| `TOU-002` | Merchant Takedown at TOU | Merchant revokes rights or takes down product before execution. | Job status set to `FAILED`; provider submission prevented. |

---

## 4. Execution & Verification Strategy
- **Local Unit Suite**: Executed via Python test drivers running all 31 unit test cases.
- **Continuous Integration**: Executed in GitHub Actions against real PostgreSQL service container, validating database migrations and model persistence.
- **Fail-Closed Rule**: Any test failure must immediately block the pipeline and prevent merges.
