# Phase 07.5.13 — User-Facing Failure Messages and Client Presentation Contracts

## 1. Overview
Shoppers interacting with Virtual Try-On must never be exposed to internal stack traces, database deadlocks, provider hostnames, or raw JSON exception objects.

FashXStudio standardizes user presentation through `backend/fashx/tryon/lifecycle/messages.py`, delivering empathetic, understandable, and actionable guidance.

---

## 2. Error Code to Shopper Guidance Catalog

| Internal Error Code | Customer-Visible Message | Suggested Action |
| :--- | :--- | :--- |
| `DATABASE_TEMPORARY` | Virtual try-on is temporarily experiencing technical delays. Retrying shortly. | Wait while we retry |
| `QUEUE_UNAVAILABLE` | Virtual try-on queue is temporarily busy. Your job is safely saved. | Wait while we retry |
| `WORKER_INTERRUPTED` | Processing worker was restarted. Resuming your try-on. | Check again shortly |
| `PROVIDER_RATE_LIMITED` | Virtual try-on is busy right now. We are pacing requests. | Wait while we retry |
| `PROVIDER_UNAVAILABLE` | We are having trouble processing your try-on. Retrying automatically. | Check again shortly |
| `PROVIDER_STATUS_TIMEOUT` | Your try-on is taking longer than expected. Continuing to monitor. | Keep this screen open or check later |
| `PROVIDER_DOWNLOAD_FAILED`| Your result is almost ready. We are retrieving it. | Check again shortly |
| `STORAGE_TEMPORARY_FAILURE`| Finalizing your try-on result. | Check again shortly |
| `PROVIDER_SUBMISSION_UNKNOWN`| We are checking the status of your try-on with the inference provider. | Do not submit the same request again yet |
| `INVALID_INPUT_IMAGE` | This photo cannot be used for virtual try-on. | Upload a clear, full-body photo |
| `UNSUPPORTED_CATEGORY` | Virtual try-on is not yet supported for this clothing category. | Try another product |
| `CONSENT_REQUIRED` | Please provide permission to process your photo for virtual try-on. | Review consent in account settings |

| `MERCHANT_PERMISSION_DENIED`| The merchant has not authorized virtual try-on for this product. | Select another product |

| `PROVIDER_OUT_OF_CREDITS` | Virtual try-on service is temporarily unavailable. | Check back later |

| `JOB_CANCELLED` | Your try-on has been cancelled. | Submit a new request if needed |
| `UNKNOWN_ERROR` | An unexpected error occurred during virtual try-on. | Try again later |

## 3. Client Status API Response Schema

When polling `GET /api/v1/tryon/jobs/{job_id}`:

### Active / Retrying Status (HTTP 200)
```json
{
  "job_id": "9fa85f64-5717-4562-b3fc-2c963f66afa9",
  "status": "RETRY_PENDING",
  "progress_stage": "provider_inference",
  "retry_scheduled": true,
  "retry_after_seconds": 12,
  "result_available": false,
  "result_url": null,
  "failure": {
    "code": "PROVIDER_UNAVAILABLE",
    "message": "We are having trouble processing your try-on. Retrying automatically.",
    "suggested_action": "Check again shortly"
  }
}
```

### Terminal Failure Status (HTTP 200)
```json
{
  "job_id": "9fa85f64-5717-4562-b3fc-2c963f66afa9",
  "status": "FAILED",
  "progress_stage": "FAILED",
  "retry_scheduled": false,
  "result_available": false,
  "result_url": null,
  "failure": {
    "code": "MAX_RETRIES_EXCEEDED",
    "message": "We could not complete your try-on this time. Please try again later.",
    "suggested_action": "Try again later"
  }
}
```
All internal tracebacks, SQL statements, and provider hostnames are strictly excluded.
