# Phase 07.5.07 — Worker Timeouts, Leases, and Heartbeat Invariants

## 1. Overview
In a distributed queue architecture, workers can crash, be evicted by cloud autoscalers (OOMKilled, spot termination), or experience network partition while inference is in flight.

FashXStudio prevents orphan jobs and zombie worker race conditions through **Worker Leases**, **Heartbeats**, and **Layered Timeouts**.

---

## 2. Layered Timeouts (`TimeoutPolicy`)

| Timeout Layer | Value | Purpose | Failure Consequence |
| :--- | :---: | :--- | :--- |
| **Provider HTTP Connect** | $5.0\text{ s}$ | Fast TCP socket connection establishment. | Connection error $\rightarrow$ retryable. |
| **Worker Heartbeat Interval** | $15.0\text{ s}$ | Frequency of worker heartbeat updates. | Heartbeat skipped. |
| **Output Download Timeout** | $30.0\text{ s}$ | Maximum duration to download generated image. | Retry download with backoff. |
| **Single Provider HTTP Request**| $30.0\text{ s}$ | HTTP read timeout for single request. | Connection timeout $\rightarrow$ submit unknown / retry poll. |
| **Worker Claim Lease** | $60.0\text{ s}$ | Worker exclusive lock duration on job. | Lease expires; eligible for reclamation. |
| **Provider Inference Deadline** | $180.0\text{ s}$ | Maximum time provider is allowed for GPU processing.| Transition to `FAILED` with `PROVIDER_STATUS_TIMEOUT`. |
| **Whole Job Deadline** | $300.0\text{ s}$ | Absolute upper bound for total request-to-result. | Sweeper terminates job to `FAILED`. |

## 3. Worker Lease Model

When a worker claims a job from `QUEUED` or `RETRY_PENDING`:
```python
lease = await service.claim_job_with_lease(job_id=job.id, worker_id="worker-1", lease_seconds=60)
```

The database executes an atomic conditional update:
```sql
UPDATE tryon_jobs
SET status = 'PROCESSING',
    worker_id = :worker_id,
    lease_token = :lease_token,
    lease_expires_at = NOW() + INTERVAL '60 seconds',
    heartbeat_at = NOW(),
    version = version + 1,
    updated_at = NOW()
WHERE id = :job_id
  AND status IN ('QUEUED', 'RETRY_PENDING')
  AND (lease_expires_at IS NULL OR lease_expires_at < NOW());
```

### Invariants Enforced
1. **Exclusive Execution**: Only one worker can claim a job at any time.
2. **Heartbeat Renewal**: Active workers renew `lease_expires_at` every 15 seconds. If a worker fails, its lease expires within 60 seconds.
3. **Stale Worker Defense**: If Worker A stalls and Worker B reclaims the job after lease expiration, Worker A's subsequent write fails because `worker_id != TryOnJob.worker_id` and `lease_token != TryOnJob.lease_token`, raising `LeaseLostError`.
