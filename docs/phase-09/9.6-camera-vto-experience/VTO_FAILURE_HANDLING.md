# VTO Failure Handling

- `mapTryOnErrorCode()` (`mobile/src/features/tryon/errors.ts`) maps backend codes (`VTO_CONSENT_REQUIRED`, `IMAGE_NOT_OWNED_OR_NOT_FOUND`, `IMAGE_NOT_READY`, `IMAGE_FORMAT_UNSUPPORTED`, `IMAGE_TOO_LARGE`, `PERSON_NOT_DETECTED`, `PRODUCT_NOT_ACTIVE`, `GARMENT_PROCESSING_NOT_AUTHORIZED`, `UNSUPPORTED_GARMENT_CATEGORY`, `VTO_RATE_LIMITED`, `VTO_SERVICE_UNAVAILABLE`, `IDEMPOTENCY_CONFLICT`, `TRYON_JOB_NOT_FOUND`, `TRYON_RESULT_NOT_READY`, `TRYON_RESULT_EXPIRED`, `SUBMISSION_UNKNOWN`) to safe shopper copy.
