# Wardrobe API Contract

- `GET/POST /api/v1/wardrobe/items`, `DELETE /api/v1/wardrobe/items/{item_id}` (existing `mobile/src/features/wardrobe/api.ts`).
- `GET/POST /api/v1/wardrobe/looks`, `GET/DELETE /api/v1/wardrobe/looks/{look_id}` (`getSavedLooks`, `createSavedLook`, `getSavedLook`, `deleteSavedLook`).
