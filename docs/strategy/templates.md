# Strategic Outreach Communication Templates

**Ethical Ground Rules**:
1. All numbers cited represent audited pilot metrics from Phase 10; never inflate conversion claims.
2. Zero use of pilot participant photographs or personal details in outreach.
3. Every outreach message must be personalized with a specific, factual reference to the recipient's work.
